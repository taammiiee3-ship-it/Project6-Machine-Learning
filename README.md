# Project 6 — Machine Learning Prediction

## What does this project do?

This project uses Machine Learning to predict an athlete's performance score based on training hours.

The project uses Linear Regression to learn the relationship between training hours and performance.

## What did I learn?

I learned how to:

- Create training data
- Train a Machine Learning model
- Use Linear Regression
- Make predictions
- Calculate the R² Score
- Use user input for predictions
- Visualize predictions

## Tools Used

- Python
- Scikit-learn
- Matplotlib
- VS Code
- GitHub

## Results

The model achieved an R² Score of 0.96 on the training data.

For example, when the user enters 7 training hours, the model predicts a performance score of approximately 79.33.

## Conclusion

The Machine Learning model learned a strong relationship between training hours and performance score in this sample dataset.

This is a learning project created to practice Machine Learning with Python.
